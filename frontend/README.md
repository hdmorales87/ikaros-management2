# Ikaros Management Frontend

Frontend independiente para Ikaros Management, construido con React 19, TypeScript, Vite y TanStack Query.

## Desarrollo

```bash
npm install
copy .env.example .env
npm run dev
```

Configura `VITE_API_URL` y `VITE_COMPANY_UUID` en `.env`. El backend Laravel debe estar disponible en la URL configurada.

## Validación

```bash
npm run build
npm run lint
```
